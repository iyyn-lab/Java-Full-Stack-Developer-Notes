## 🗺️ Detailed Learning Checklist

Use the checkboxes below (`- [ ]`) to track your learning progress directly in your repository.

### Phase 1: Foundations, Build Tools & DSA

- [ ] **1. Core Java**
  - Variables, Data Types, Operators, and Control Flow
  - Object-Oriented Programming (Encapsulation, Inheritance, Polymorphism, Abstraction)
  - Exception Handling, Collections Framework, Generics, Streams API, and Multithreading
- [ ] **2. Maven**
  - Project Object Model (`pom.xml`), Dependency Management, and Build Lifecycles
- [ ] **3. Gradle**
  - Build scripts (`build.gradle`), Tasks, Plugins, and High-Performance Builds
- [ ] **4. JUnit**
  - Unit Testing Fundamentals, Assertions, Annotations, and Test-Driven Development (TDD)
- [ ] **5. Git**
  - Version Control, Branching, Merging, Rebasing, and GitHub Workflows
- [ ] **6. DSA (Data Structures & Algorithms)**
  - Arrays, Linked Lists, Stacks, Queues, Trees, Graphs, Sorting, and Searching Algorithms



### Phase 2: Database Connectivity & Web Basics

- [ ] **7. JDBC (Java Database Connectivity)**
  - Drivers, Connections, `Statement`, `PreparedStatement`, and ResultSets
- [ ] **8. Servlets and JSP**
  - Request/Response Lifecycle, Session Management, and Dynamic Web Pages
- [ ] **9. REST API and Web Services**
  - HTTP Methods (`GET`, `POST`, `PUT`, `DELETE`), Status Codes, JSON/XML Payloads, and Statelessness



### Phase 3: ORM & Data Persistence

- [ ] **10. What Is an ORM Tool?**
  - Object-Relational Mapping Concepts, Impedance Mismatch, and JPA Specifications
- [ ] **11. Hibernate**
  - Entity Mapping, SessionFactory, HQL (Hibernate Query Language), Caching, and Relationships (`@OneToMany`, `@ManyToMany`)



### Phase 4: The Spring Ecosystem & Spring Boot

- [ ] **12. Spring Framework**
  - Inversion of Control (IoC), Dependency Injection (DI), ApplicationContext, and Spring Beans
- [ ] **13. Spring REST API Using Spring Boot**
  - `@RestController`, `@RequestMapping`, DTOs, Validation, and Exception Handling
- [ ] **14. Spring JDBC**
  - `JdbcTemplate`, RowMapper, and Simplified Database Operations
- [ ] **15. Spring Data JPA**
  - `JpaRepository`, Custom Finder Methods, `@Query`, Pagination, and Sorting
- [ ] **16. Project Using Spring Boot MVC**
  - End-to-End CRUD Application Architecture, Controllers, Services, and View Integration



### Phase 5: Security, Logging & NoSQL Projects

- [ ] **17. Spring Security**
  - Authentication, Authorization, Security Filter Chain, CSRF, and Password Encoding
- [ ] **18. JWT (JSON Web Tokens)**
  - Token Generation, Signature Verification, Claims, and Stateless Authentication
- [ ] **19. OAuth2**
  - Third-Party Login (Google/GitHub), Resource Servers, and Authorization Flows
- [ ] **20. Logging in Java Using Log4j**
  - Log Levels (`INFO`, `DEBUG`, `WARN`, `ERROR`), Appenders, and Production Auditing
- [ ] **21. Spring Boot MongoDB Full Project**
  - Document Databases, `MongoRepository`, Aggregations, and Full-Stack Implementation



### Phase 6: Containerization, Cloud & AI Integration

- [ ] **22. Docker for Java Developers**
  - Images, Containers, `Dockerfile`, Multi-Stage Builds, and `docker-compose`
- [ ] **23. Cloud Deployment**
  - Deploying Spring Boot Applications and Databases to Cloud Providers (AWS/Render/Azure/GCP)
- [ ] **24. Spring AI**
  - Prompts, ChatClient, Embeddings, Vector Databases, and AI Orchestration in Java
- [ ] **25. DeepSeek Open Source Using Ollama and Spring AI**
  - Running Local LLMs with Ollama and Integrating DeepSeek Models into Spring Boot



### Phase 7: Microservices & Event-Driven Architecture

- [ ] **26. Microservices**
  - Service Discovery (Eureka), API Gateway, Config Server, Feign Client, and Circuit Breakers (Resilience4j)
- [ ] **27. Spring Boot + Kafka**
  - Event-Driven Architecture, Topics, Partitions, Producers, and Consumers



### Phase 8: DevOps & Infrastructure as Code (IaC)

- [ ] **28. Linux**
  - File System Navigation, Permissions, Bash Scripting, Process Management, and Networking
- [ ] **29. Ansible**
  - Configuration Management, Playbooks, Inventory, and Agentless Server Automation
- [ ] **30. Jenkins**
  - Continuous Integration / Continuous Deployment (CI/CD) Pipelines, Jenkinsfile, and Automated Builds
- [ ] **31. Terraform**
  - Infrastructure as Code (IaC), Providers, State Management, and Automated Cloud Provisioning
